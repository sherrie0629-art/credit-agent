## 文档结构

**P1 执行摘要（一页纸）**
现状痛点 → 三年目标 → 组织从 24 人到 14 人的结构变化 → 人效提升倍数 → 首年净收益与回收期 → 四个季度里程碑。CEO 只读这一页也能决策。

**第一部分：为什么必须重构（3 页）**
- 中型信贷广告主投放团队的典型工时结构（调价/查素材/合规复核/报表各占比）
- "加人才能加量"的线性增长陷阱：人均可管预算天花板测算
- Agent 能力边界地图：哪些环节可全自动、哪些必须 Human-in-the-Loop（合规终审、风控策略、预算总盘）

**第二部分：渗透率分阶段路线图（5 页）**
- L0–L4 成熟度模型：影子运行 → 建议采纳 → 半自动 → 全自动带阈值 → 自主经营
- 每阶段的准入条件、退出条件、可授权决策范围（预算调幅上限、素材上线权限、合规豁免范围）
- 渗透率 KPI 体系：Agent 决策占比、建议采纳率、人工推翻率、平均决策时延、自动化覆盖预算比例
- 四季度里程碑甘特图 + 每阶段风险与回滚机制

**第三部分：业务流程重构前后对比（6 页）**
三条核心链路各给"改造前 / 改造后"泳道图与 SLA 对比：
- 投放优化闭环：日会调价 → Agent 分钟级预算再分配 + 人工审阅例外
- 素材合规闭环：人工初审+法务复核（2–3 天）→ 自动扫描 Auto-Fix + 法务只看例外（分钟级）
- 风控-增长闭环：月度回溯 → 离线转化回传驱动的 CPS 实时优化
每条链路标注：环节数变化、平均时长、返工率、责任人变化

**第四部分：岗位级人机分工与新组织（7 页）**
- 新组织架构图：从"渠道分工"转向"Agent 监管 + 策略 + 数据"三条线
- 逐岗位表：原岗位 → 工作项拆解 → Agent 承接比例 → 保留/转岗/裁撤建议 → 目标编制
  覆盖：投放优化师、素材/创意、文案、数据分析、合规专员、投放主管
- 三个新岗位完整 JD：Agent 运营官（AgentOps）、增长策略负责人、转化数据工程师（含职责、能力模型、面试要点、薪酬带宽区间）
- 转岗与人才盘点方案：能力雷达评估表、90 天再培训路径、留任激励与离职成本处理
- 变革管理：抵触点识别、沟通节奏、试点团队选择原则

**第五部分：财务测算与 ROI（4 页）**
- 人力成本前后对比表（按岗位编制 × 薪酬带宽）
- 人效指标：人均可管预算、单人日均决策数、素材上线周期
- 效果侧收益：CPS 下降假设、合规风险成本规避、素材迭代提速带来的增量
- 三年现金流表 + 首年 ROI + 回收期 + 敏感性分析（悲观/基准/乐观三档）
- 明确列出全部假设参数来源，便于客户替换成自己的数据

**第六部分：落地路径与合作建议（2 页）**
- 90 天启动计划（诊断 4 周 → 试点 6 周 → 推广）
- 咨询交付物清单与客户侧配合要求
- 与 CreditAgent AI 平台的衔接点（哪些结论直接落到产品配置里）

**附录（2 页）**
组织诊断问卷、Agent 授权阈值配置表模板、术语表。
