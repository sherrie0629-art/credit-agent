## 目标

产出一份面向运营 / 市场业务团队的 PDF 使用手册：不讲代码与技术栈，只讲**业务逻辑原理 + 日常怎么用**，读完能独立上手系统并理解 Agent 为什么这么决策。

交付物：`/mnt/documents/CreditAgent_AI_运营手册.pdf`（沿用应用的深色科技风：深底、霓虹青/柠檬绿点缀、中文无衬线字体）。

## 文档结构（约 14 页）

**第一部分 · 5 分钟看懂这套系统**
1. 封面
2. 一句话定位 + 它替你做什么 / 不替你做什么（职责边界表：Agent 负责调预算、调出价、换素材、拦合规；人负责目标设定、审批大额变更、素材调性把关）
3. 核心理念：为什么优化目标是 **CPS（每笔放款成本）** 而不是 CPL —— 用一张"两个渠道 CPL 相同但 CPS 差 2 倍"的对照表说明前端便宜≠后端赚钱

**第二部分 · 业务原理（读懂 Agent 的脑子）**
4. 四个 Agent 各管什么：Planner（预算/出价）、Creative（素材迭代）、Compliance（合规拦截）、Execution（下发与回滚），配一张职责流转图
5. 层级模型：广告系列 → 广告组 → 素材，各层能被 Agent 改什么
6. 决策是怎么产生的：采集（每 15 分钟）→ 触发阈值 → 推理链 → 置信度 → 执行 or 挂起审批。解释每个触发指标（CPL / 后端授信通过率 / CPS / ROAS）的业务含义与常见阈值
7. 素材疲劳怎么判定：CTR 衰减、曝光频次、CPL 抬升、素材年龄四个信号如何合成一个分数，HEALTHY / WATCH / FATIGUED 三档分别会触发什么动作
8. 合规护栏：禁用话术、贷款期限 ≥61 天、APR ≤36% 等规则的业务由来，以及被拦截后运营该怎么改
9. 数据怎么串起来的（业务视角）：落地页留资 → CRM 授信/放款事件 → 归因到素材与广告组 → 回传给 Google/Meta → 平台学习更准。解释"回传健康度"低会让 Agent 判断失真

**第三部分 · 上手操作**
10. 决策指挥中心：四个 KPI 卡怎么读、推理流怎么看、审批队列什么时候批准 / 否决 / 回滚（附判断清单）
11. 预算矩阵：半自动 vs 全自动的区别与选择建议、如何手动改预算与暂停广告组
12. 素材中心三个页签：疲劳雷达 → AI 生成变体 → 合规审计 → A/B 赛马结算的完整闭环走一遍
13. 全链路归因 & 离线转化回传：漏斗与渠道下钻怎么看，回传成功率异常时的排查动作
14. 日常 SOP：每日 15 分钟 / 每周 / 每月各做什么；常见问题速查（数据为空、决策一直挂起、素材反复被拦截、CPS 上升）；术语表（CPL / CPS / ROAS / 授信通过率 / 疲劳分 / 回传 / Human-in-the-Loop）

## 实施方式

1. 先读取现有业务规则源文件（合规规则、疲劳打分、决策阈值、各页面文案），确保手册里写的阈值和界面完全一致，不编造数字。
2. 用 HTML + CSS 排版 → 无头浏览器打印为 PDF（与之前架构文档同一套方法，中文字体与深色底渲染稳定）。
3. 逐页转图做视觉 QA：检查中文断行、表格溢出、深色底对比度、图表标签遮挡，修完再交付。
